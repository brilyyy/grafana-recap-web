## Purpose

User-facing preferences for theme and background display mode, plus app setup panel for superadmins.

## Main Function

- Toggle light/dark/system theme.
- Toggle between default and alternative background display.
- Superadmin: access app setup panel for initial configuration.

## APIs

- Client-side only (theme and background stored in local state)
